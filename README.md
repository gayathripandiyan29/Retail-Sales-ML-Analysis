Retail Sales Analysis & Customer Behavior Prediction

📌 Project Overview

This project focuses on analyzing online retail sales data and applying Machine Learning techniques to understand customer purchasing behavior, segment customers, predict repeat purchases, and analyze future sales trends.

The project combines Data Analytics, Machine Learning, and Power BI to generate meaningful business insights and support data-driven decision-making.

🎯 Project Objectives

- Analyze retail sales performance.
- Understand customer purchasing behavior.
- Identify valuable and at-risk customer segments.
- Predict customer repeat purchases within 90 days.
- Evaluate Machine Learning model performance.
- Identify important features influencing predictions.
- Analyze and forecast sales trends.
- Build an interactive Power BI dashboard.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI
- Machine Learning

📊 Project Modules

1. Data Cleaning and Preprocessing

- Handled missing values and duplicate records.
- Processed retail transaction data.
- Prepared cleaned data for analysis and Machine Learning.

2. Exploratory Data Analysis (EDA)

- Analyzed sales trends.
- Identified top-selling products and countries.
- Explored customer purchasing patterns.
- Analyzed transaction and revenue information.

3. RFM Analysis

Used Recency, Frequency, and Monetary (RFM) analysis to understand customer purchasing behavior and identify different customer segments.

4. Customer Segmentation using K-Means

Applied K-Means Clustering to group customers based on their purchasing behavior.

Methods used:

- Elbow Method
- Silhouette Score
- Cluster Analysis
- Customer Segment Comparison

5. Customer Purchase Prediction

Developed Machine Learning models to predict whether customers would make a repeat purchase within the next 90 days.

Models used:

- Logistic Regression
- Random Forest Classifier

6. Model Evaluation

Evaluated model performance using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

7. Feature Importance Analysis

Analyzed the important features influencing customer repeat purchase predictions.

8. Sales Forecasting

Analyzed historical sales patterns and generated future sales trend predictions.
