Retail Sales Analysis & Customer Behavior Prediction

📌 Project Overview

This project focuses on analyzing online retail sales data and applying Machine Learning techniques to understand customer behavior, segment customers, and predict repeat purchases.

It combines Data Analytics, Machine Learning, and Power BI to generate meaningful business insights and support data-driven decision-making.

🎯 Project Objectives

- Analyze retail sales performance.
- Understand customer purchasing behavior.
- Segment customers based on RFM analysis.
- Predict customer repeat purchases within 90 days.
- Identify important features influencing predictions.
- Forecast future sales trends.
- Visualize insights through an interactive Power BI dashboard.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Power BI
- Machine Learning

📊 Project Modules

1. Data Cleaning and Preprocessing

- Handled missing values and duplicate records.
- Processed sales transactions.
- Prepared cleaned data for analysis and modeling.

2. Exploratory Data Analysis (EDA)

- Analyzed sales trends.
- Identified top-selling products and countries.
- Explored customer purchasing patterns.

3. RFM Analysis

Used Recency, Frequency, and Monetary values to understand customer purchasing behavior and identify customer segments.

4. Customer Segmentation

Applied K-Means Clustering to group customers based on purchasing behavior.

Methods used:

- Elbow Method
- Silhouette Score
- Cluster Analysis

5. Customer Purchase Prediction

Developed Machine Learning models to predict whether customers would make a repeat purchase within the next 90 days.

Models used:

- Logistic Regression
- Random Forest Classifier

6. Model Evaluation

Evaluated model performance using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix

7. Feature Importance

Analyzed important features influencing customer repeat purchase predictions.

8. Sales Forecasting

Analyzed historical sales patterns to estimate future sales trends.

9. Power BI Dashboard

Created an interactive dashboard containing sales analysis, customer segmentation, purchase prediction insights, and ML analysis visuals.
